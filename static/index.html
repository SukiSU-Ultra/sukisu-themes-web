SMTP 邮件

用于注册验证、找回密码和审核结果通知。密码留空表示保持现有密码。

Gmail 需填写完整邮箱地址

未配置 SMTP 时邮箱注册会返回 503；本地开发可设置 THEME_DEV_MODE=1，邮件链接写入日志。

Gmail 示例：smtp.gmail.com / 587 / STARTTLS，用户名填写完整 Gmail 地址，密码填写 Google 应用专用密码。

GitHub OAuth
