上传主题

管理员上传会直接发布；管理器投稿会先进入待审核。纯本地存储，上限 1.2 GB。

支持 Markdown：**粗体**、*斜体*、`代码`、[链接](https://example.com)。输入 @github、@bilibili、@coolapk、@telegram 等可提及其他网站。
同样支持 Markdown 与 @ 网站提及。
单个主题包 ≤ 16 MB，图片 ≤ 2 MB（自动压缩为 WebP）

资源后端

本地磁盘模式直接读写数据目录；对象存储模式把主题包、预览图、截图和头像放到桶里，meta 与 catalog 仍保存在本地。

兼容 AWS S3、Cloudflare R2、MinIO、Backblaze B2。凭证留空表示沿用已保存的值；切换后端会自动迁移资源并校验大小。
